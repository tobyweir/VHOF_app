What is a Higher Order Function?

A Higher Order Function is a function that either takes another function as input or returns another function as output.

This website allows for 3 Higher Order Functions to be applied to the tiles on the grid, these being Fold (Foldr and Foldl depending on the direction) , Filter and Map.

More information is available on these functions in the other information boxes and the links below.

https://en.wikipedia.org/wiki/Higher-order_function

What are Foldl and Foldr?

foldl and foldr are higher order functions which reduce a list of elements to a single element, an example use case is using a fold operation on a list with the (+) function to calculate the total sum of the list

foldl and foldr operate in two different ways and can produce very different results, in the above example they would produce the same output as (+) is associative but other functions such as (-) would not.

Lets use an example list of [1 , 2 , 3 , 4 , 5] and the function (-)

This is the same as having a row of tiles with the same values.

For Foldr we can view the rightmost tile as the accumulator, the accumulator is the value that will be passed along between each calculation, as each calculation needs 2 values an accumulator is needed at the start of the fold operation.

calling this function in a language like Haskell would look like:

foldr accumulator function list

foldr 5 (-) [1 , 2, 3, 4]

This can be seen as putting a minus symbol between each value:

1 - 2 - 3 - 4 - 5 (accumulator taken to the right to begin the operation)

The difference between foldr and foldl is where the accumulator is taken to start and the order of operations

For foldr this means that

1 - 2 - 3 - 4 - 5

becomes

(1 - (2 - (3 - (4 - 5))))

with a result of 3

For Foldl the accumulator can be viewed as the leftmost tile.

foldl 1 (-) [2, 3, 4 , 5]

again can be viewed as

1 - 2 - 3 - 4 - 5

but the order of operations is different

((((1 - 2) - 3) - 4) - 5)

with a result of 13

Here are the same functions written in javascript

const foldr = [1, 2, 3, 4].reduceRight((acc, x) => x - acc, 5);

console.log(foldr); // 3

const foldl = [2 , 3 , 4 , 5].reduce((acc , x) => acc - x , 1);

console.log(foldl);

What are filter and map?

Filter and Map are higher order functions, both operate on each element of the list.

Filter checks if a current element satisfies the function is was provided and removes it from the list if it does not

For example when the value 1 is passed into the function (x > 10), false will be the output, this means that filter will not keep the value

Map applies the function it was given to each element of the list and replaces the element with the output

For example when map applies (x + 1) to 3 the result will be 4, and this value will become part of the new list.

How to use this Website?

Begin by hovering over a tile and clicking the add tile button or use a preset to add a number of tiles

Next you can edit the tiles value by clicking on the number, by default this is 0

Now you can use the change rotation button to swap the direction of the fold

Double clicking on any tile in the selected column/row will begin the fold

Use the controls to experiment between different Higher Order Functions and the arguments they take.

Filter and Map do not need a direction so Change rotation is used to swap between selecting columns/rows.
